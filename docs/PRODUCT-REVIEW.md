## ما هو مميز فعلًا (الخندق)

1. **جرافيك يفهم المعنى**: ميزان عند "أخف/أثقل"، حبال دمية عند "يعتمد على"، جمهور يضيء عند "أغلب المبرمجين". الأدوات الأخرى تضع قوالب عامة.
2. **أوامر المونتاج المنطوقة**: "اقطع هذه اللقطة"، "زوم على وجهي"، "اعرض موقعي هنا" — نُفذت كلها فعليًا. لم نجد أداة سوقية تفعل هذا.
3. **العربية بجدية**: تصحيح اللهجة يدويًا، RTL سليم، كلمات لاتينية لا تنقلب، خطوط حقيقية.
4. **قابل للتعديل**: كل شيء كود — تعديل كلمة دون إعادة الفيديو.
5. **تقليد أسلوب ريل مرجعي** وتحويله لقواعد.

## نقاط الضعف الحقيقية

1. **عدم الثبات والتكلفة**: كل ريل يُكتب من الصفر (~300–400 سطر) → جودة متغيرة واستهلاك رموز عالٍ. هذا أكبر خطر.
2. **الإعداد صعب لغير المبرمج**: Node 22 + ffmpeg + Python + faster-whisper + نموذج 3 GB + HyperFrames. التقدير: 2–4 ساعات لغير المبرمج.
3. **الرسومات بسيطة**: صور ظلية SVG، أقل من الرسم اليدوي في الريل المرجعي.
4. **جودة المصدر**: ملفات واتساب (480p) تحد من النتيجة مهما كان المونتاج.
5. **ادعاءات أكبر من الواقع**: الوصف يذكر 16:9 لكنه غير مدعوم؛ لا دعم لعدة مقاطع أو موسيقى خلفية أو Windows.
6. **مستخدم واحد فقط حتى الآن** — لا يوجد دليل سوقي بعد.

## لمن هو؟

- **مناسب**: صانع محتوى عربي تقني/تعليمي، يشترك أصلًا في Claude، ينشر 2–4 ريلز شرح أسبوعيًا، يريد جرافيك مصممًا لا قوالب، ويقبل 15–20 دقيقة للريل.
- **غير مناسب**: من ينشر يوميًا بكميات (CapCut/Submagic أسرع وأرخص)، غير المبرمجين حاليًا، المونتاج السينمائي أو متعدد الكاميرات.

## الشيء الوحيد الذي يضاعف القيمة ×10

**مكتبة مكونات ثابتة + مولّد (`build_reel.py`)**: كابشن، زوم، تقسيم شاشة، انتقال ضبابي، مؤثرات صوتية، مشاهد جاهزة (ميزان، فقاعة، ختم، قائمة) تُقرأ من `timing-map.json` وملف أسلوب. الوكيل يختار ويملأ بدل أن يكتب. المتوقع: وقت وتكلفة أقل بكثير، ونتيجة ثابتة.

## ما لا يهم الآن (لا تبنه)

واجهة إعدادات رسومية، دعم كل أنواع الفيديو، أساليب كابشن خاصة (HyperFrames فيها 35)، النشر العام قبل الثبات.

## الخطوات التالية (بالترتيب)

1. **المكونات والمولّد** (المذكور أعلاه) — يبدأ بالكابشن والزوم والمؤثرات ووضع `quick`.
2. **الإعداد بأمر واحد**: سكربت تثبيت + faster-whisper إلزامي + فحص إصدار ffmpeg و yt-dlp + ذكر حجم النموذج + مسار Linux/WSL.
3. **تنظيف الوثائق**: توثيق `--silences`، حذف 16:9 أو دعمه، توحيد الحقائق المكررة، تحديث README إلى 0.5.0، تثبيت إصدار HyperFrames.
